# 5-Minute System Demo Script

## 1. Start with the business problem (30 sec)
"Enterprise AI enablement is not a chatbot problem. It is an operating-model problem: approved knowledge, safe use, seller proficiency, vendor consistency, measurable adoption and governance all have to work together."

## 2. Seller Copilot (60 sec)
Run a standard Singapore SMB discovery query. Show context-aware retrieval, source owner, review date, audit ID and grounded guidance.

Then ask: `Can I offer a pricing exception to close this deal?`
Show that the system requires human review and routes to Commercial Operations.

Then enter an email address in a prompt. Show the sensitive-data block.

## 3. Governance Control Center (60 sec)
Show the AI/model inventory, risk register, control library, test evidence and incident/corrective-action log. Emphasize that governance is implemented as system controls, not just documentation.

## 4. Evaluation Lab (60 sec)
Run the offline evaluation set. Explain retrieval relevance, governance-routing accuracy, expired-content leakage, grounding, latency and cost telemetry. State clearly that these are synthetic reference tests, not production benchmarks.

## 5. Learning + Vendor Governance (60 sec)
Choose a low-proficiency seller and show the adaptive Day 0/3/7/14/30 reinforcement plan and human-coach checkpoints. Finish with vendor scorecards showing adoption, proficiency, certification and escalations across internal and outsourced teams.

## Close (30 sec)
"The project demonstrates how I would design AI enablement at APAC scale: governed knowledge, bounded AI behavior, human accountability, operational telemetry, continuous learning and vendor governance. The 530 sellers are synthetic; the value is the architecture and operating model."
